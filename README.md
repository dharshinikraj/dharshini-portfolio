# Dharshini — HUMAN × AI Portfolio

A dark-pink, highly animated Human-Centered AI portfolio built with Vite, vanilla JavaScript, CSS and Three.js.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Notes

- The 3D sci-fi core in the hero is the only intentionally futuristic AI visual.
- Other animations are project-specific and communicate the problem/solution story.
- Replace placeholder GitHub / LinkedIn URLs in `index.html` with your real profile links before publishing.
